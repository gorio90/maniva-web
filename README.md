# maniva beauty · web

Sitio estático (HTML/CSS/JS, sin build) para www.manivabeauty.com.ar.
Catálogo Pink Mask con pedido por WhatsApp.

- `config.js`: número de WhatsApp, Instagram y textos de envíos.
- `data/productos.js`: precios del mes (salen de la pestaña "Precios Web" de la planilla). Se actualiza cada mes.
- `img/p/<SKU>.jpg`: fotos oficiales de Pink Mask, sin editar.

Reglas de precio: los descuentos por cantidad aplican solo a esmaltes, bases, tops y Builder,
pagando en efectivo o por transferencia. Ningún precio baja del mínimo de Pink Mask.
